# Term collections

Grouped word choices for recurring technical topics. Entries read as
`term`: rule. A rule that names a preferred term means *use the preferred
term instead*. When a project glossary or the source material defines a term
differently, the project definition wins.

## Accessibility terms

- **people-first language**: Default to "person with" or "person who"; identity-first ("blind person") OK when the community prefers it.
- **offensive terms**: Never use "maimed", "impaired", "crippled", "lame", "handicapped", "dumb", "mute", "stupid".
- **blind, low vision**: Use "person who is blind" or "person with low vision"; not "sight-impaired" or "vision-impaired".
- **cognitive, developmental, learning disabilities**: Use these; not "slow learner", "mentally handicapped", "differently abled", "special needs".
- **deaf**: Use "person who is deaf" or "person with a hearing disability"; not "hearing-impaired".
- **functional needs**: Use (or name the specific need), not "special needs".
- **has [condition]**: Write "has multiple sclerosis"; not "affected by", "stricken with", "suffers from", "victim of", "an epileptic".
- **limited mobility**: Use "person with limited mobility" or "wheelchair user"; not "crippled" or "lame".
- **limb difference**: Use "person with a prosthetic limb", "limb difference", or "amputation"; not "missing a limb" or "birth defect".
- **person with a disability**: Use; "disabled person" acceptable; not "the handicapped" or "people with handicaps".
- **person with autism**: Use; "autistic person" or "neurodivergent person" acceptable; not "Asperger's".
- **person without a disability**: Use; "non-disabled person" acceptable; not "normal" or "healthy".
- **unable to speak**: Use "uses sign language" or "uses synthetic speech"; not "dumb", "mute", or "non-verbal".

## AI and bot terms

- **AI**: Use "AI"; don't spell out "artificial intelligence". Prefer describing benefits over the technology itself.
- **bot, chatbot, virtual agent**: Use "bot"; "chatbot" or "virtual agent" once to clarify, then "bot".
- **conversation as a platform (CaaP)**: Technical use only; define and spell out first; "CaaP", not "CAAP"; no hyphens as modifier.
- **conversational user interface (CUI)**: Avoid for customers; spell out first ("conversational UI" OK), then "CUI".
- **intelligent, intelligence**: Use to describe AI benefits; use "intelligent technology", not "smart technology".
- **new terms**: Check that a suitable term doesn't already exist before inventing one.
- **personal digital assistant**: Use for a named, persona-based assistant bot; not "virtual assistant" or "intelligent personal assistant".
- **social chatbot, relationship chatbot**: Use, not "emotional chatbot" or "personified chatbot".
- **voice-activated device**: OK for the device category.
- **voice user interface (VUI)**: Avoid for customers; spell out first ("voice UI" OK), then "VUI".

## Bits and bytes

- **abbreviations**: Spell out on first mention unless the audience knows them; abbreviate only with numerals (128 TB).
- **spacing**: Space between numeral and abbreviation (512 GB); hyphenate as modifier (a 650-MB limit).
- **singular vs plural**: Spelled-out unit is singular only for exactly 1 (1 megabit, 0.5 megabits).
- **of**: Attach nouns with "of": 200 MB of available space.
- **commas**: Use commas in numbers with four or more digits (1,024 MB).
- **bits per pixel, bits per second**: Abbreviate bpp, bps; don't use bps as a synonym for baud.
- **byte, kilobit, megabit, gigabit**: Spell out except in UI (B, Kb, Mb, Gb).
- **KB, MB, GB, TB, PB, EB, ZB**: Use these; not K, M, meg, G, "KByte", "M byte", and similar.
- **KiB, MiB, GiB, TiB**: Use for kibibyte, mebibyte, gibibyte, tebibyte.
- **Kbps, Mbps, Gbps, KBps, MBps**: Use these; don't write "Mb per second", "MB per second", and similar.

## Cloud computing terms

- **as a service (-aaS)**: Don't coin new "-aaS" terms; describe what the service provides.
- **cloud**: Lowercase; mostly an adjective. Prefer "cloud computing" or "cloud services" over "the cloud".
- **cloud bursting**: Technical audiences; define first; hyphenate before a noun (cloud-bursting configuration).
- **cloud computing, cloud platform, cloud services**: Two words, lowercase; "cloud platform" for technical audiences only.
- **cloud native**: Technical audiences; hyphenate before a noun (cloud-native app); not "born in the cloud" or "cloud-born".
- **cloud OS**: Don't use; use "platform as a service (PaaS)".
- **community cloud**: Don't use; use hybrid cloud, private cloud, or hosted private cloud.
- **content delivery network**: Lowercase; always spell out; don't use "CDN".
- **cross-tenant**: Hyphenate in all positions.
- **edge, edge computing**: Lowercase; define unless familiar; write "at the edge", not "on the edge".
- **elastic computing, elastic cloud computing**: Avoid; describe the capability. If needed, define on first mention.
- **hosted service**: Use for a service or app hosted by a provider and delivered over the internet.
- **hosting provider**: Use "cloud hosting provider" or "web hosting provider"; not "hoster".
- **hybrid cloud**: Technical audiences; define first. Otherwise say "hybrid model".
- **IaaS, PaaS, SaaS, ITaaS**: Spell out first with abbreviation in parentheses; never all caps; no hyphens as modifiers.
- **multicloud**: One word, no hyphen; technical audiences.
- **multitenant, multitenancy**: One word, no hyphen; for general audiences, say "used by multiple tenants".
- **on-premises, off-premises**: Hyphenate always; not "on-premise"; don't write "on-premises cloud".
- **private cloud, hosted private cloud**: Define on first mention.
- **serverless**: One word, no hyphen.

## Computers and devices

- **adapter**: Use, not "adaptor".
- **client, server**: Use only when hardware vs software is clear; else "client computer" or "server computer"; never "box".
- **computer, PC**: Use "computer"; "PC" only when space-constrained, consistently. Not "mobile computer" or "portable computer".
- **connect, disconnect**: Use for linking devices or connecting to a network.
- **desktop**: Only for a nonportable computer; not a synonym for "computer".
- **device, mobile device**: Use "device" as the general term; add "mobile" only when mobility matters.
- **disc, disk**: "Disc" for CDs and DVDs; "hard drive", not "hard disk", "fixed disk", or "disk drive".
- **display, screen, monitor**: "Display" for any output device; "screen" for usable area; "monitor" for standalone units.
- **drive**: Write "drive C", not "C: drive"; "network drive", not "remote drive".
- **handheld device**: Only for small line-of-business devices; don't use "handheld" as a noun.
- **input devices**: Name the device (mouse, pen, touchpad); not "pointing device" or "input device"; "pen", not "stylus".
- **install, uninstall**: Use for drivers and apps.
- **machine**: Use "computer" generally; "machine" OK in technical and virtualization content.
- **network adapter**: Use, not "network card".
- **phone, mobile phone, smartphone**: Prefer "phone"; not "cell phone", "cellular phone", or "wireless phone".
- **set up**: Use for preparing hardware or software for first use.
- **tablet, laptop**: Use only for that class of computer; not "slate" or "notebook".
- **touchscreen**: One word; use sparingly.
- **turn on, turn off**: Use, not "power on/off" or "switch on/off".
- **USB**: Don't spell out; adjective only (USB drive).
- **wearable device**: Use when the distinction matters; don't use "wearable" as a noun.

## Date and time

- **24/7**: Don't use; write "all day, every day" or "always".
- **AM, PM**: Capitals, preceded by a space (10:45 AM); always include with clock times.
- **dates**: Write "July 31, 2016"; not "31 July 2016"; no ordinals (1st, 23rd).
- **days, months**: Capitalize; abbreviate only when space is very tight, without periods (Mon, Jan).
- **midnight, noon**: Use alone, not "12:00 noon"; midnight starts the new day.
- **seasons**: Avoid; use months or quarters. If needed, name the hemisphere; lowercase.
- **time ranges**: Use "to" in text (10:00 AM to 2:00 PM); unspaced en dash in schedules.
- **time zones**: Capitalize; include for multi-region events; give UTC offsets without spaces (UTC+7).
- **UTC**: Write "Coordinated Universal Time"; abbreviate UTC, never CUT; prefer it over GMT.
- **units of time**: Abbreviate ms, min, sec, h; spell out day, week, month, year, microsecond, nanosecond.

## Keyboard terms

- **access key, shortcut key**: Use "keyboard shortcut" for general audiences; distinguish only in developer content, explaining both.
- **arrow keys**: Not "direction keys", "directional keys", or "movement keys".
- **Esc**: Use, not "Escape".
- **F1–F12**: Capital F, no space before the number.
- **key combination, key sequence**: Use "keyboard shortcut" generally; in technical content, distinguish and explain.
- **keyboard shortcut**: Use, not "accelerator key", "hot key", "fast key", "quick key", or "speed key".
- **keystroke**: Use, not "keypress".
- **numeric keypad**: Use on first mention; not "numerical keypad" or "numeric keyboard".
- **on-screen keyboard**: Hyphenate; not "virtual keyboard", "soft keyboard", or "visual keyboard".
- **select (keys)**: Use "select", not "press", "hit", "strike", or "depress"; "use" when clearer (use the arrow keys).

## Mouse, touch, and pen interaction

- **input-neutral wording**: Prefer describing the interaction (select, choose) over device-specific actions.
- **click, double-click, right-click**: Don't add "on"; hyphenate double-click and right-click.
- **drag**: Use, not "click and drag" or "drag and drop".
- **hover over, point to**: Use, not "mouse over".
- **mouse**: Plural is "mice".
- **pan, flick**: Don't use "drag" or "scroll" as synonyms.
- **pointer, cursor**: Use "pointer"; "cursor" only for technical audiences or the insertion location; not "insertion point".
- **scroll**: Use only for beginners; otherwise "move through".
- **tap, double-tap**: Use for touch and pen; don't add "on". Use "tap and hold", not "touch and hold".

## Security terms

- **anti-malware**: Hyphenate; adjective only.
- **antiphishing, antispyware, antivirus**: No hyphen; adjectives only. Use "antivirus" to contrast with antispyware.
- **black hat hacker**: Prefer "malicious hacker", "computer criminal", or "unauthorized user".
- **bullet-proof**: Don't use.
- **deceptive software**: Don't use; use "unwanted software".
- **hacker, hack**: Use "malicious hacker" or "unauthorized user"; "hack/hacker" only for developers or positive contexts.
- **insecure**: Don't use to mean "not secure".
- **lock**: Don't use to mean "protect".
- **malicious code, malicious user**: Don't use; use "malware" and "malicious hacker".
- **malware**: Use instead of "malicious software"; define as "malicious software" on first mention if needed.
- **spyware**: Use only for software confirmed as spyware.
- **trojan horse, trojan**: "Trojan" OK for technical audiences.
- **unwanted software**: Use as the umbrella term for spyware, adware, and similar.
- **vulnerability**: Not for intentional behavior; qualify on first mention (product, administrative, physical); else "security issue".
- **white hat hacker**: Prefer "computer security expert".

## Special characters

- **acute accent, grave accent, caret, circumflex**: Not "accent acute", "accent grave", or "accent circumflex"; "backtick" OK for `.
- **angle brackets**: Left and right angle bracket; < and > are also less than and greater than signs.
- **braces**: Use for { }, not "curly brackets"; opening and closing brace.
- **ellipsis**: One set of three dots; "ellipses" only for multiple sets; no spaces between dots.
- **equal sign**: Not "equals sign".
- **exclamation point**: Not "exclamation mark".
- **minus sign**: Use the true minus sign (−), not an en dash.
- **multiplication sign**: Use ×; asterisk or x only to match software.
- **number sign**: Use for #, not "pound sign"; "hashtag" in social media; "pound key" for phone keypads.
- **opening, closing**: Name pairs as opening and closing (parenthesis, bracket, quotation mark).
- **pipe, vertical bar**: Names for |.
- **plus sign**: Don't use + in place of "and", "over", or "plus".
- **quotation marks**: Not "quotes", "quote marks", or "single quotes".
- **slash**: Not "virgule".
- **symbols in text**: Prefer words to symbols for screen readers ("1 through 10", not "1–10").
- **tilde**: Don't use ~ to mean "about" or "approximately".

## Units of measure

- **numerals**: Use numerals for measurements, even under 10; add a leading zero before decimals (0.75).
- **spacing**: Space between number and unit (13.5 inches); hyphenate as modifier (13.5-inch display).
- **abbreviations**: Only with numerals; no period except "in." for inch.
- **commas**: Use for four-plus digits; for years, pixels, and baud only five-plus digits (1920 × 1080).
- **singular vs plural**: Singular only when the number is 1 (1 point, 0 points).
- **dimensions**: Spell out "by" (10 by 12 ft); use × with spaces for tiles, resolutions, paper sizes.
- **area, volume**: Use sq ft, m², cu ft, m³.
- **baud**: Don't abbreviate; not "baud rate" (redundant).
- **degrees**: ° for temperature; "deg" for angles.
- **dialog units, microsecond, nanosecond**: Don't abbreviate.
- **dpi, PPI**: OK when readers know them.
- **Hz, kHz, MHz, GHz**: Spell out first, then abbreviate with numerals; capitalize Hertz and Hz.
- **half-inch**: Hyphenate as adjective; not "half an inch"; "0.5 in." when precise. Avoid "in." in localized text.
- **pixels**: Don't abbreviate "px" for screen or camera resolution; OK in tight design content.
- **units**: cm, ft, in., km, m, mi, mm, g, kg, oz, lb, pt, MP.
