# Term list

Alphabetical word-level decisions: spelling, compounding, capitalization,
preferred and avoided terms, and usage distinctions. Entries read as
`term`: rule. Look up a word here when the core references don't settle it.
When a project glossary or the source material defines a term differently,
the project definition wins.

## Numbers and symbols

- **2D, two-dimensional**: Spell out first if unfamiliar; then 2D. Always hyphenate "two-dimensional".
- **3D, three-dimensional**: Prefer 3D; spell out first if unfamiliar. Always hyphenate "three-dimensional".
- **8.5" × 11" paper**: Use this form; straight quotation mark for inches, × not x.

## A

- **abort**: Avoid for general audiences; use end, close, stop, or cancel. Only for API names. Never "abortion".
- **above**: Don't use for "earlier" or as "the above section"; use "preceding", "previous", "earlier", or a link.
- **access**: Verb OK for "obtain access to"; not for start, create, or open.
- **accessible**: Reserve for usability by people with disabilities; not a synonym for "simple" or "easy".
- **actionable**: Avoid; write "that you can act on".
- **add**: Use for add-ins and add-ons (remove to undo); use "install" for apps.
- **add-in, add-on**: Add-in for software extending a program; add-on for attached hardware.
- **adjacent selection**: Prefer "multiple selection"; never "contiguous selection".
- **administer**: Use, not "administrate".
- **administrator, admin**: Use either or "system administrator"; lowercase except account-type or group names.
- **afterward**: Use, not "afterwards".
- **against**: Don't use for running on a platform (use "on"); OK for queries or evaluation against data.
- **alarm**: Don't use for general attention sounds; use "beep" or specific wording.
- **alert**: OK for automated messages in technical content; otherwise "notification"; not a synonym for "reminder".
- **alias**: Don't use for email address, account name, or distribution group.
- **allow, allows**: Don't say a product allows, enables, or lets the user; OK for permit/deny semantics.
- **allow list**: Two words, lowercase; not "allowlist" or "whitelist"; not a verb—write "add to an allow list".
- **alphabetical**: Use, not "alphabetic".
- **alphanumeric**: Use for letters and numerals only; not "alphanumerical".
- **ampersand (&)**: Don't use for "and" in text or headings; OK when discussing HTML or code.
- **and/or**: Avoid; "or" usually suffices.
- **and so on**: Don't use; be specific or use "such as". Never after "for example" or "such as".
- **anti-malware**: Hyphenate; adjective only.
- **antialiasing**: One word, no hyphen.
- **antispyware, antivirus**: One word, no hyphen; adjectives only.
- **app, application**: Prefer "app"; "application" OK in technical content; not "application program".
- **appendices**: Plural of appendix, not "appendixes".
- **applet**: Only for browser-downloaded (Java) programs; otherwise name the program, app, or add-in.
- **application developer, app developer**: Don't use; use "developer", "software developer", "web developer", or "programmer".
- **application file, app file**: Don't use; name the file or say "program file".
- **argument vs. parameter**: Be consistent; argument = value passed to a function; parameter = named value treated as constant.
- **as well as**: Don't use as a synonym for "and".
- **ask**: Don't use as a noun; use "request" or "task".
- **assembly language**: Use, not "assembler" or "machine language"; hyphenate as adjective.
- **assistive**: Use for technologies helping people with disabilities, only in that context.
- **assure, ensure, insure**: Ensure = make sure; insure = provide insurance; assure = state positively.
- **attribute**: Don't use as a synonym for "property".
- **audiobook**: One word.
- **author**: Don't use as a verb for making things; use write, create, design, build. "Authoring tools" OK technically.
- **auto-**: Don't hyphenate (autoscale) unless needed for clarity; don't coin new auto- words.
- **avg**: Spell out "average" except in space-constrained UI.

## B

- **back end, back-end**: Not a synonym for server, database, or network for general audiences; noun two words, adjective hyphenated.
- **back up, backup**: Verb is two words; noun and adjective one word.
- **backbone**: Avoid for general audiences; no need to define for technical ones.
- **backlight**: One word.
- **backspace**: One word; OK as a verb.
- **backtab**: Don't use; write Shift+Tab.
- **baseline**: One word.
- **beep**: Use, not "alarm" or "tone", for a beeping sound.
- **below**: Don't use for "later" or as "the code below"; use "following", "later", or a link.
- **bi-**: Don't hyphenate (bidirectional, bimonthly) unless needed for clarity.
- **big data**: Lowercase.
- **big-endian, little-endian**: Hyphenate; OK for technical audiences (most significant byte first vs last).
- **bio**: OK for "biography"; allow space for full translations.
- **bitmap**: One word; don't use for any graphic—use illustration, figure, or picture.
- **black box**: Don't use.
- **blacklist**: Never use; use "block list" (or "blocked senders list").
- **blade**: Don't use; use "pane".
- **blank**: Don't use as a verb for emptying a cell; use "clear".
- **block list**: Two words, lowercase; not "blocklist"; not a verb—write "add to a block list".
- **blog**: Noun or verb; not "weblog". "Blogger" for author, "blogroll" for link list.
- **Blu-ray Disc**: Use this spelling; abbreviate "BD" after first mention.
- **blue screen**: Don't use for a crash; verb "stop", noun "stop error".
- **Bluetooth**: Always capitalize; add ® on first mention.
- **board**: Don't use for peripheral interface hardware; use "card" (video card).
- **bold**: Adjective only; not "bolded", "boldface", or "boldfaced"; "regular font" for neither bold nor italic.
- **bookmark**: One word.
- **Boolean**: Always capitalize.
- **boot**: Not a verb; use "turn on" or "start". "Boot sector" OK technically; prefer "startup".
- **bottom left, bottom right**: Use "lower left", "lower right"; hyphenate as adjectives.
- **box**: Don't use as a synonym for client or server hardware; "checkbox" is one word.
- **breakpoint**: One word.
- **broadcast**: Past tense is "broadcast", not "broadcasted"; "webcast" for web broadcasts.
- **browse**: For manual scanning only; use "search" or "find" for search features; "browse through" a list.
- **bug fix**: Don't use; use "software update" for the general category.
- **build**: General audiences: use "create". Technical: OK for compile and link, or a prerelease version.
- **bulk**: Avoid as an adverb ("bulk edit"); use "in bulk" or "multiple"; no compounds or hyphen.

## C

- **-core**: Hyphenate processor adjectives: single-core, dual-core, multi-core.
- **C, C++, C#**: OK as adjectives; don't hyphenate (no "C-based"); write "based on C++".
- **cable**: Don't use as a verb.
- **cabling**: Not a synonym for cables; OK for a combination of cables, connectors, and terminators.
- **cache vs. disk cache**: Use cache for duplicated fast memory; disk cache for RAM holding disk reads.
- **calendar**: Don't use as a verb; use schedule or list.
- **call back, callback**: Verb is two words; noun/adjective one word. Write "callback function", not just "callback", for developers.
- **call out, callout**: Verb is two words; noun/adjective one word.
- **can, may**: Prefer describing the action over "can". Use can for ability, might for possibility, not may.
- **cancel, canceled, canceling, cancellation**: One l in canceled/canceling; two in cancellation. Use cancel for ending requests/processes early.
- **carry out vs. run**: Use run, not carry out, for commands, macros, and programs.
- **Cascading Style Sheets (CSS)**: Capitalize the technique; say "the CSS file" or "style sheet", not "a CSS".
- **catalog**: Use catalog, not catalogue.
- **category axis**: Lowercase, no hyphen; first use "category (x) axis", then "x-axis".
- **cell phone, cellular phone**: Don't use. Cellular is OK in cellular data network or connection.
- **center on**: Use center on, not center around.
- **character set**: Not a synonym for code page; a character set appears on a code page.
- **chart**: Don't use as a verb for entering data; use plot. Use chart, not graph (bar chart, pie chart).
- **check in**: OK as a verb phrase (check in code); don't use as a noun.
- **check mark**: Use check mark for the mark showing an item is selected.
- **checkbox**: One word; not check box or box. Use select and clear, not check/uncheck or turn on/off.
- **child folder**: Don't use; use subfolder, subdirectory, or folder.
- **click**: Avoid; use device-neutral verbs like select. Use click only for mouse-specific actions.
- **clickstream, clickthrough**: One word each; avoid for a general audience.
- **client**: Don't use for a person; use customer.
- **client side, client-side**: Use client for general audiences; avoid client-side as adjective, hyphenate if needed.
- **client/server**: Always use the slash.
- **clipboard**: Copy or move things to the clipboard, not onto it.
- **cloud native, cloud-native**: Lowercase; hyphenate before a noun. Prefer cloud-based or built for the cloud; OK for developers.
- **co-**: Don't hyphenate co- words (coauthor, coordinate) unless needed to avoid confusion.
- **code page**: Not a synonym for character set.
- **code point**: Two words.
- **codec**: Don't spell out; use only for technical audiences.
- **color map**: Two words.
- **column format**: Use instead of columnar or columnlike.
- **command line, command-line**: Noun is two words; hyphenate as adjective. Enter commands at a command prompt, not on a command line.
- **command prompt**: Use instead of C prompt, command-line prompt, or system prompt.
- **company vs. organization**: Use company for businesses; organization also covers schools, nonprofits, government.
- **compile**: OK as verb or adjective (compile time); don't use as a noun.
- **compute**: OK as verb; as noun/modifier (compute hours) only for technical audiences.
- **connect**: Use for attaching to a network; not a synonym for sign in or map a drive.
- **console**: Use console window/application only for technical audiences; not a synonym for snap-in.
- **context-sensitive**: Always hyphenate.
- **contiguous selection**: Don't use; use multiple selection or adjacent selection.
- **control**: For general audiences, don't call UI elements controls; name the element.
- **corrupted**: Avoid; describe damaged files empathetically. Don't use corrupt.
- **country or region**: Use where disputed territories may be included; otherwise country. Not geo or geography.
- **crash**: Don't use; use fail (hardware) or stop responding (programs, OS).
- **cut, cut-and-paste**: Don't use cut as a verb; use delete, move, or copy. Cut-and-paste OK only as adjective.
- **cyber-**: Don't hyphenate: cybersecurity, cyberspace, cyberattack.

## D

- **dark mode**: Lowercase, two words.
- **data binding**: Two words.
- **data, datum**: Use data with a singular verb; don't use datum or "the data are".
- **data record**: Don't use; use record.
- **database**: One word.
- **datacenter**: One word.
- **datagram**: One word.
- **datasheet**: One word.
- **debug**: Use only for software development; not a synonym for troubleshoot.
- **decrement**: Technical audiences only; means decrease by one, not a synonym for decrease.
- **default**: Don't use as a verb; write "by default" or "the default is".
- **defragment**: Don't abbreviate to defrag.
- **deinstall**: Don't use except to match an API or UI; use remove or uninstall.
- **delete**: Use for removing data/files; not a synonym for remove. Don't use cut or erase for delete.
- **demilitarized zone (DMZ)**: Use perimeter network; mention DMZ or screened subnet once if needed.
- **deprecated**: Avoid for technical audiences; don't use for general audiences. Use obsolete or similar.
- **deselect**: Don't use; use clear (check boxes) or cancel the selection.
- **destination**: Prefer a precise term (folder, website); don't use target as a synonym.
- **destination drive, destination file**: Avoid; be specific. Don't use target drive or target file.
- **device driver, driver**: Name the specific driver (printer driver); define driver for general audiences.
- **DevOps**: Spell and capitalize as DevOps.
- **dial-up**: Adjective only, always hyphenated; use dial as the verb.
- **dialog box, dialogue**: Write dialog box, not dialog, dialogue box, or pop-up window. Spell conversation as dialogue.
- **different**: Use different from; different than only before a clause; never different to. Don't use for many/various.
- **dimmed**: Say not available for unusable commands; appears dimmed only to describe appearance.
- **directory**: Prefer folder; use directory for file-system structure or to match an API.
- **disable, disabled (functionality)**: Avoid unless matching UI; use turn off, off, turned off, or not available.
- **disabled (person)**: Don't use; write person with a disability or a specific people-first term.
- **disjoint selection**: Avoid; use multiple selection or list the items.
- **disk space**: Avoid; use storage or storage space for capacity. Say drive, not disk, for partitions.
- **display adapter, display driver**: Don't use; use video card and video driver.
- **DNS**: Spell out as Domain Name System, not Domain Name Server. Don't use dynamic DNS or DDNS.
- **document**: Use for text files; use file for general or mixed-type references.
- **domain**: Define on first use; meaning differs across databases, networks, and internet addresses.
- **dot-com**: Don't use.
- **double buffering**: Noun two words; hyphenate as adjective; not a verb (say "uses double buffering").
- **downgrade**: Use only for downgrade rights/licenses/products, for audiences that understand it.
- **download**: Use for intentional data transfer; install for apps/drivers. State what and where. Not for opening webpages.
- **drag, drag and drop**: Use drag or move; drag-and-drop only as adjective. Don't use click and drag.
- **drill down, drill up, drill through**: Two-word verbs for data/reports; hyphenate drill-down/drill-up adjectives; drillthrough noun. Not for general exploring.
- **drive name**: Use instead of drive specification, designator, or designation.
- **drive resource**: Use for a drive or part of one shared on a server.
- **dropdown**: One word; use as an adjective (dropdown list), not as a noun. Not drop-down.
- **DVD**: Don't spell out; say DVD drive, not DVD player; avoid redundant "DVD disc".
- **dynamic-link library (DLL)**: Hyphenate; spell out first unless known; use .dll for extension. Don't use dynalink.

## E

- **e-words**: Don't coin new e- words; hyphenate existing ones (e-book, e-commerce, e-learning, e-discovery, e-sports). Email is the exception.
- **e-form**: Don't use; use form.
- **earlier**: Use earlier, preceding, or previous instead of above; use or earlier, not or lower, for versions.
- **edutainment**: Don't use.
- **e.g.**: Don't use; use for example, such as, or like.
- **either/or**: Don't use; write a complete phrase (either X or Y).
- **email**: One word, no hyphen; OK as verb. Use email message for one item; give noun context for localizers.
- **embed**: Use embed, not imbed.
- **emoji, emoticons**: Plural is emoji; prefer emoji to emoticons. Never replace words or carry meaning; avoid in serious content.
- **enable, enables, enabled**: Avoid "X enables/allows/lets you". Use turn on and on/available unless matching UI.
- **end**: Use for stopping communications and connections; use close for apps.
- **endline**: One word.
- **endpoint**: One word.
- **ensure, insure, assure**: Ensure = make sure; insure = provide insurance; assure = state positively or make confident.
- **enterprise**: For IT pros/developers only, preferably as adjective (enterprise deployment).
- **entry field**: Don't use for text boxes; use box. OK in database contexts.
- **erase**: Not a synonym for delete.
- **et al.**: Don't use except in citations with 3+ authors; use and others.
- **etc.**: Don't use; be specific or use such as/like with examples.
- **euro**: Lowercase; plural euros; symbol before amount in US content. Avoid eurozone/euroland in formal content.
- **executable, .exe**: Use as adjectives; write "an .exe file". Use program file for general audiences.
- **execute**: Use run, not execute, except to match UI or API. Execution as noun is OK.
- **exit**: Don't use for closing an app; use close.
- **expand, collapse**: Use for showing or hiding subentries in folders or outlines.
- **expose**: Don't use for UI; use make available or display. OK for object services in OOP.
- **extend**: Use extend, not grow, for selections.
- **extension, file name extension**: Use instead of file extension.

## F

- **fail**: General audiences: hardware only; use stop responding for software. Technical: OK for error conditions.
- **fail over, fail back, failover, failback**: Verb two words; noun/adjective one word. Technical audiences only.
- **FALSE**: Uppercase for return values, or follow the language's casing.
- **Far East**: Don't use; use East Asia or Asia.
- **far-left, far-right**: Don't use; use leftmost or rightmost. Don't rely on direction as the only location cue.
- **fax**: Lowercase; OK as noun, verb, adjective.
- **field**: Don't use for text-entry boxes; use box. OK in database and technical contexts.
- **file**: Prefer a specific term (document, workbook); file OK for storage or mixed types.
- **file attributes**: Lowercase attributes: hidden, system, read-only, archive.
- **file name**: Two words, no hyphen; one word only for programming identifiers.
- **finalize**: Don't use; use finish or complete.
- **find and replace**: Use find and replace as separate verbs, not a noun phrase. Say all occurrences, not global.
- **first line, first-line**: Noun two words; hyphenate as adjective.
- **flush**: Don't use for text alignment; use left-aligned/right-aligned. OK technically (flush the buffer).
- **flyout**: Avoid for general audiences; technical: adjective only (flyout menu), never a verb.
- **folder**: Use folder for file containers; directory only for file-system structure or APIs.
- **following**: Introduce lists, tables, code, or art with the following, this, or these plus a noun. Don't use below.
- **font, font style**: Use font style/size, not type style/size; bold and italic, not bolded/italicized; regular font for plain text.
- **foo, foobar, fubar**: Never fubar; avoid foo/foobar, prefer meaningful placeholders like Example.exe.
- **foreground program**: Use instead of foreground process (technical).
- **format, formatting**: Use format for overall layout; formatting/formatted for specific character or paragraph formatting.
- **fourth-generation language**: Spell out first; then 4GL.
- **frameset**: Developers only; use frames for scrollable page regions.
- **freeze, frozen**: Don't use; use stop responding.
- **friendly name**: Don't use; use display name.
- **from vs. on**: Use from for a starting place or time; on for where to select a command.
- **front end, front-end**: Noun two words; hyphenate before a noun. Technical only when needed; otherwise say interface, program, or app.
- **full screen, full-screen**: Noun two words; hyphenate adjective before a noun.
- **function**: Don't use function to mean API, or API to mean function.

## G

- **gallery**: Use for a collection to select from; not for a store or marketplace.
- **game pad**: Two words.
- **garbage collection, garbage collector**: OK for technical audiences; collector is the runtime component.
- **GB**: Also means Great Britain; don't use UK, Great Britain, and England interchangeably.
- **General Data Protection Regulation (GDPR)**: Spell out first; precede the noun with "the".
- **general protection fault**: Spell out first; then GP fault.
- **given**: Don't use to mean specified, particular, or fixed.
- **global**: OK for worldwide and technical scope (global variable). Don't use for find-and-replace; use all occurrences.
- **glyph**: Use symbol for button/icon images; glyph only in font/character discussions.
- **graphic, graphics, graphical**: Graphic = an image (noun); graphics = the field; use graphical as adjective.
- **graphics adapter**: Don't use; use video card.
- **gray, grayed out**: Don't use for unusable options; use not available or appears dimmed.
- **greater, better**: Don't use to mean "or later" for versions.
- **greylist**: Spell greylist; use only for the spam-reduction technique.
- **gridline**: One word.
- **group box**: Two words; technical audiences only.
- **group, newsgroup**: Use newsgroup, not group, for internet discussion groups.
- **grow**: Don't use as a transitive verb for increasing size; use increase, extend, or similar.

## H

- **half inch**: Hyphenate as adjective (half-inch); not "half an inch"/"one-half inch"; use 0.5 in when precise.
- **handle**: For numbered handles, space before the number: handle 0, handle 1.
- **handshake**: One word; define on first mention for general readers.
- **hang**: Don't use; use "stop responding" (program can't close itself).
- **hard copy**: Two words, noun only; don't use "soft copy".
- **hard-code, hard-coded, hard-coding**: Always hyphenate; technical audiences only.
- **hardwired**: One word; avoid for general audiences.
- **HDMI**: Use the abbreviation as an adjective, with "an" (an HDMI cable).
- **he/she**: Don't use; write bias-free (they, you, or rephrase).
- **header**: Not a synonym for heading or header file; OK as short for file header (HTTP/HTML header).
- **heading**: Use for article/section titles, not "head" or "header".
- **hexadecimal**: Don't abbreviate as "hex"; write 21h or 0xFFFE, no space, uppercase A–F.
- **hierarchical menu**: Use "submenu"; OK only when explaining menu types to technical readers.
- **high-level-language compiler**: Hyphenate as shown.
- **high-quality**: Always use, never "quality" alone as an adjective.
- **high-resolution**: Always hyphenate; don't use "hi-res".
- **higher**: Don't use "or higher" for versions (use "or later"); use "faster" for processor speed; OK for resolution.
- **hint**: Don't use as a note heading; use "tip".
- **hit**: Don't use for pressing keys; use "page view"/"page request" for web traffic.
- **home directory**: Don't use; use "root directory" (developers) or "top-level folder".
- **home page**: Two words; use "home" for a site's main page; don't use "start page".
- **honeypot**: Avoid; if unavoidable, define on first mention.
- **host name**: Two words, except for programming element names.
- **hot link**: Don't use for hyperlinks or for linked data updates.
- **hot spot, hotspot**: Not for links; "hot spot" = pointer pixel; "hotspot" = wireless access site.
- **how-to**: Hyphenate as adjective only (how-to article); not a noun; never capitalize "to".
- **HTML**: Don't spell out; if needed, "Hypertext Markup Language".
- **HTTP, HTTPS**: Don't spell out unless audience needs it; uppercase for protocol; lowercase http:// in URLs.
- **hyperlink**: Use "link" or "hyperlink", not hot spot/hot link/shortcut/jump; "go to" a link, not "click on".

- **imbed**: Don't use; use "embed".
- **impact**: Noun only; as a verb use "affect".
- **in use**: Two words.

- **inbound**: Use "incoming" for email, not "inbound".
- **incoming, outgoing**: Use for messages, not "inbound"/"outbound".
- **increment**: As a verb, means increase by one or a set interval; as a noun, the interval.
- **indent, outdent**: Use "indent"/"indentation"; don't use "outdent".
- **index**: Plural "indexes"; "indices" only in math.
- **info**: OK only in informal content; prefer "information".

- **inline**: One word, no hyphen.

- **insecure**: Don't use; use "not secure".
- **inside**: Use "inside", not "inside of".
- **install**: Use for adding apps/drivers, "uninstall" to remove; noun is "installation", not "install".

- **invalid, not valid**: Prefer "not valid" or a more specific description; machine translation handles it better.
- **invite**: OK as a noun or verb for requesting participation in a meeting or event.
- **invoke**: Technical audiences only, for functions or processes.

- **issue**: Not a verb; not a synonym for "problem".
- **IT pro**: Use "IT pro", not "IT professional"; never spell out IT.
- **italic**: Adjective only; don't use "italics" or "italicized"; say "regular font" for neither bold nor italic.

## J

## L

- **labeled, labeling**: One l.

- **launch**: Don't use for opening apps; use "open" or "start".
- **lay out, laid out, layout**: "lay out" (verb), "laid out" (past), "layout" (noun).
- **leading**: Use "leading" (opposite of "trailing") for spaces/characters at the start of strings.
- **leave**: Don't use for closing an app; use "close".
- **left align, left-aligned**: Hyphenate "left-aligned"; don't use "left-justified".
- **left, leftmost, left-hand**: Don't use "left" alone or "left-hand"; use "upper left", "leftmost"; never directional cues alone.
- **legacy**: Don't use for prior versions; use "previous", "earlier", or be specific.
- **legal**: Only for matters of law; use "valid" otherwise.
- **less vs. fewer vs. under**: "less" for mass amounts, "fewer" for countable items; never "under" for quantities.
- **let, lets**: Avoid "lets/allows/enables you to"; focus on what the reader does.
- **leverage**: Not a verb; use "use" or "take advantage of".
- **license terms**: Not "EULA" or "licensing terms".
- **lifecycle**: One word.
- **-like**: Close up (maillike) unless root ends in "ll" or has 3+ syllables (bell-like, computer-like).
- **line of business**: Hyphenate as adjective only; don't abbreviate as LOB.
