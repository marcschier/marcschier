# Whole-file editorial pass

1. **Ask once in fix mode.** After the review fixes, list every current path under `source/` changed by those fixes and every complete primary `*NodeSet2.xml` for the selected specifications, including unchanged ones. Exclude dependency models, unrelated local changes and generated publication outputs. Ask with **Include Claudism Killer** or **Skip (default)**. Only an explicit opt-in authorizes the pass. Do not offer it in a read-only audit or where the user has limited all edits to the local rubric.
2. **Invoke `claudism-killer`.** Load the installed skill through the host's skill mechanism. Pass the approved file list as whole files, not a patch. Read each text file from start to finish, including lines untouched by the original edits; for a large file, record contiguous ranges so none are silently skipped. Inspect the entire NodeSet and edit only its eligible prose. Account for each target: edited, unchanged, non-prose or protected, or not examined with the reason. Opt-in covers Claudism Killer only; any Sloptrim pass requires separate consent. If the skill is unavailable, report the optional pass as not run and resume sign-off without installing a replacement.
3. **Preserve authority and content.** The repository rubric still governs style sign-off. Edit human-readable prose, including descriptions in structured files; preserve markup, data and behavior. Protect NodeSet identifiers, references, model shape, values and schemas, and keep XML valid. For generated prose, apply any supported edit at its authoritative source and regenerate; do not hand-edit a generated copy. Use the [preservation ledger](evidence.md#information-preservation-ledger) for uncertain equivalence or prospective losses. Declining to make a suggestion does not exclude the rest of the file from review.
4. **Verify the final delta.** Include any accepted prose edits and regenerated descriptions in the freeze, publication checks and independent preservation review. If later sign-off fixes add an eligible source file, include it in the opted-in whole-file pass before the final freeze. Keep the optional pass's disposition separate from the rubric verdict.
