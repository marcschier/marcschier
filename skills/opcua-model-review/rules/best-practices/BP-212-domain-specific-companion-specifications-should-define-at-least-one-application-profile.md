# BP-212 - Domain-specific Companion Specifications should define at least one application Profile

**Authority:** OPC 11030 is a non-mandatory whitepaper. Its own wording is retained below; a deviation is advisory unless a normative specification or an explicitly adopted policy establishes a requirement.

## Rule

Profiles should combine several Conformance Units. It is recommended that concrete, domain-specific Companion Specifications define at least one application Profile  -  bundling everything needed for a complete product, including protocol-level requirements  -  to improve interoperability within that domain.

## Applicability

Domain-specific Companion Specifications.

## Exceptions and evidence limits

None stated.
