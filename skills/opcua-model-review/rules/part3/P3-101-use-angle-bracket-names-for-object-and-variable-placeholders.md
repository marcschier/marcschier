# P3-101 - Use angle-bracket names for Object and Variable placeholders

## Rule

Enclose Object/Variable placeholder BrowseName and DisplayName text in angle brackets.

## Audit

Review the recommended convention without turning it into a mandatory naming syntax or applying it to Method placeholders.
