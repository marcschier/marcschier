# P3-108 - Prefix Interface names with I

## Rule

Use I as the first letter of an Interface name.

## Audit

Treat this explicitly recommended naming convention as advice, not as the definition of an Interface.

- [OPC 10000-3 v1.05.06, clause 4.10.2](https://reference.opcfoundation.org/specs/OPC-10000-3/v1.05.06/4.10.2)
