# P3-166 - Publish and manage standard Role metadata consistently

## Rule

Provide a useful base set of Roles, allow configured system-specific Roles, and support the well-known Roles where appropriate.

## Audit

Separate recommended base Roles/permissions from mandatory assignment, publication, administration, and enforcement behavior; suggested permissions are not a fixed profile.
