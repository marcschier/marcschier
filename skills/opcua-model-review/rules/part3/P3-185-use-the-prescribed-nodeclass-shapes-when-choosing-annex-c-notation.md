# P3-185 - Use the prescribed NodeClass shapes when choosing Annex C notation

## Rule

If using Annex C's simple notation, use its NodeClass shapes and type/instance typography consistently.

## Audit

Inspect rendered diagrams. Annex C notation is optional; the rule does not require every document to adopt it.
