# P3-186 - Draw Reference direction and shortcuts consistently

## Rule

Within Annex C notation, use the defined symmetric/asymmetric arrows and the correct direction and marks for any selected Reference shortcut.

## Audit

Inspect figure arrowheads and source/target labels; using the generic labeled Reference instead of a shortcut is allowed.
