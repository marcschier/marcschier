# P3-191 - Interpret AddressSpace figures using their declared convention

## Rule

For the introductory Part 3 figure convention, preserve its NodeClass/BrowseName labeling and source-to-target Reference arrows.

## Audit

Read the figure's legend before interpreting shapes. This introductory convention is not a mandate that every companion diagram use Annex C notation.
